# Brianna Gauna Coaching website

Public website for Brianna Gauna's nutrition coaching.

## Getting started

Install dependencies with `npm install`, then start the development server with `npm run dev`. Create a production build with `npm run build`.

## Editing the text

All of the website's text is in `src/content.ts`. Text in `[square brackets]` is a placeholder and shows highlighted in yellow during `npm run dev`. Replace every placeholder before publishing.
